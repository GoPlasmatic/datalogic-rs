# Changelog

All notable changes to `datalogic-rs` (the core crate and every language
binding) are documented in the repository-root
[CHANGELOG.md](https://github.com/GoPlasmatic/datalogic-rs/blob/main/CHANGELOG.md),
which is the single canonical changelog. The release workflow refuses a
tag whose version has no dated section there.

This file exists because the crates.io package is built from this
directory. It carries no entries, released or unreleased: a copy here
would be packaged into every release and go stale between them.
